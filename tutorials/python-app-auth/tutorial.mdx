<Intro>

## What you will build

A Python script, `app_auth.py`, that authenticates as an application, without a user, with OAuth 2.0 credentials and the client credentials flow:

* It exchanges a client ID and client secret for an app token using [requests-oauthlib](https://requests-oauthlib.readthedocs.io/en/latest/).
* It calls the [portals/self](https://developers.arcgis.com/rest/users-groups-and-items/portal-self/) endpoint with that token and prints the privileges the token carries.

You will create the OAuth credentials in the portal first, then write the script that uses them.

<details>
<summary>Check prerequisites</summary>
<p>You will need an ArcGIS Location Platform, ArcGIS Online, or ArcGIS Enterprise account that can create developer credentials. In ArcGIS Online and ArcGIS Enterprise, that means a user type of Creator or higher.</p>
<p>To run the script: Python 3.12 or later and <code>requests-oauthlib</code> (<code>pip install requests-oauthlib</code>), which installs <code>oauthlib</code> too.</p>
</details>

## Create the OAuth credentials

Create the credentials for your script in [your portal](https://developers.arcgis.com/documentation/glossary/arcgis-portal/):

1. Go to **Content** > **My content** > **New item**.
2. Click **Developer credentials**.
3. Select **OAuth 2.0 credentials (_For app authentication_)**.
4. Select **Private application with selected privileges**, so the token gets only the privileges you grant.
5. Select **No item access**. This script reads no items; for your own app, grant access only to the items it needs.
6. Leave the privileges off. This script needs none; for your own app, enable only the ones it calls.
7. Leave the referrer URLs empty. A backend script doesn't need them: they help only when the token ends up in a web browser.
8. Fill in the item details.
9. Review the summary and create the item.
10. Copy the **Client ID** and the **Client Secret**.

</Step>

<Step id="load-library" file="app_auth.py" region="library">

## Import the library

Import two classes:

- `BackendApplicationClient`, from oauthlib, tells the session to use the client credentials flow, for a backend client with no user. It also stores the client ID.
- `OAuth2Session`, from requests-oauthlib, is a `requests` session that gets the token and adds it to every request you send with it.

</Step>

<Step id="token-endpoint" file="app_auth.py" region="token-endpoint">

## Build the token endpoint

The script requests its token from the portal's OAuth 2.0 token endpoint: the portal URL followed by `/sharing/rest/oauth2/token`.

</Step>

<Step id="oauth" file="app_auth.py" region="oauth">

## Set up the OAuth session

Create the client with your client ID, and the session from the client. The session uses it to request the token and to send your requests with it.

`auto_refresh_url` and `auto_refresh_kwargs` let the `OAuth2Session` request new tokens with the refresh token instead of the client secret.

</Step>

<Step id="token" file="app_auth.py" region="token">

## Request a token

Call `fetch_token` with the client secret. The ArcGIS REST API expects the client ID and the client secret as parameters of the POST request, so set `include_client_id=True`.

The session stores the token in its `token` attribute.

</Step>

<Step id="request" file="app_auth.py" region="request">

## Make a request

Send requests to the ArcGIS REST API or to ArcGIS services through the session: it adds the token to each one in the `Authorization` header. The script uses `get()`, and the other `requests` methods, such as `post()`, work the same way.

The script calls [portals/self](https://developers.arcgis.com/rest/users-groups-and-items/portal-self/), which returns the application's title and the privileges of its token, among other details.

</Step>

<Step id="run-script">

## Run the script

Run the script. It prints the title of the credentials item and the privileges of the token:

```
> python app_auth.py
Title: "Tutorial: App Authentication with python requests-oauthlib"
Has the following privileges:
    - premium:user:basemaps
```

</Step>

<Outro>

Your script authenticates as an application. To act on behalf of your users instead, [sign them in with OAuth 2.0 in a browser app](../arcgis-js-sdk-user-auth/).

</Outro>
